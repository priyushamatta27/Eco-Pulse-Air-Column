# 🌱 Eco Pulse Air Column

🏆 **1st Prize Winner – Project Expo**

## 📌 Overview
Eco Pulse Air Column is a smart air purification system designed for urban traffic areas. It is integrated into street poles to reduce air pollution using real-time monitoring and automated filtration.

## 🚨 Problem Statement
Urban areas suffer from high levels of air pollution due to vehicle emissions (CO, NOx, benzene), which negatively impacts public health.

## 💡 Solution
This system:
- Detects air pollution using sensors (MQ-135, PM2.5)
- Automatically activates purification using fans & filters
- Uses relay-based control for energy-efficient operation

## ⚙️ Technologies Used
- Arduino
- MQ-135 Gas Sensor
- PM2.5 Sensor
- Relay Module
- Embedded C

## 🔄 Working Principle
1. Sensors detect pollution levels
2. Data is processed by Arduino
3. If threshold exceeds:
   - Relay activates fan
   - Air passes through filters
4. Clean air is released
